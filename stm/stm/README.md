# StudyFlow - Student Task Manager

A responsive React task manager created from the supplied assignment brief.

## Features

- Add, complete, and delete tasks
- Form validation for blank tasks
- All, Pending, and Completed filters
- Total, completed, and remaining task statistics
- Confirmation dialog before deletion
- Empty and error fallback states
- Browser local-storage persistence
- Responsive, accessible interface
- Reusable React components, including a `Card` component using `children`

## Run locally

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The production files are generated in `dist/`.
